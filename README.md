## ✨ Features

- Product listing page with zoom & rating plugins
- Add-to-cart functionality (jQuery MyCart)
- Customer registration (`kaydol.html`) saved to MySQL via PHP
- Responsive Bootstrap layout

## 🚀 Getting Started

1. Install a local server stack such as **XAMPP**.
2. Copy the project into `htdocs` and create a MySQL database named `uye`.
3. Start Apache & MySQL, then open `http://localhost/E-Commerce/`.

> The static pages also work by simply opening `index.html`.

## Description: 
- The registration system needs WampServer, and the project files must be placed in the `www` folder for the database to work. The site has Home, Food and Contact sections. The Home button leads to the home page; the Register button opens the sign-up page and the submitted data is stored in the database; the Food button opens a drop-down menu linking to the product pages; Contact scrolls to the contact menu at the bottom. The cart icon on the right collects the items and food you add so you can buy them all together. Products to buy are listed below in 4 different sections, and pressing "Add to cart" puts the product into the cart. Further down are special offers, and at the very bottom the contact section. The quick-scroll button in the bottom right corner takes you back to the top of the page. Finally, pressing "Complete shopping" finishes the order.
